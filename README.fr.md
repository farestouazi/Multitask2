# Multitask 2

Recréation en Java d'une version PC offline du jeu Multitask 2 (IcyLime, 2011). Le joueur doit gérer plusieurs mini-jeux simultanément à l'aide du clavier. La partie se termine dès qu'un mini-jeu est perdu, et le score dépend du temps de survie.
